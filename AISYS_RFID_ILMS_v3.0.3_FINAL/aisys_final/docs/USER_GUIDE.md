# User Guide

1. Sign in with an assigned staff account.
2. Search books by title, author or accession.
3. For tagging, validate the item first and associate a unique RFID tag.
4. Use checkout/renew/checkin endpoints or the staff UI workflow built around them.
5. Use handheld RFID reads for shelf inventory.
6. Gate events are recorded and unauthorized events queue notifications.
7. Dashboard and reports provide operational visibility.
8. Administrators manage configuration and audit evidence.

All demo data is synthetic. Do not enter real member information into the candidate environment.
